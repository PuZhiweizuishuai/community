# 2026-11-15

## 后端全量升级：Spring Boot 2.4.1 / Java 11 → Spring Boot 4.1.2 / Java 25

- `pom.xml`：parent 4.1.2、java.version 25；MyBatis starter 2.1.0→4.1.0、mysql-connector-java→com.mysql:mysql-connector-j 9.7.0、jjwt 0.9.1→0.13.0、Lombok 交 parent(1.18.48)、commons-lang3 交 parent(3.20.0)；新增 AWS SDK v2 `s3`+`url-connection-client` 2.59.1；移除 druid/fastjson/minio/EasyCaptcha(system)/jaxb-api/hateoas/reactor-netty/javadoc 插件/includeSystemScope。
- **关键坑**：JDK 23+ 起 javac 不再扫描 classpath 发现注解处理器，必须在 maven-compiler-plugin 配 `annotationProcessorPaths` 指向 lombok，否则全部 getter/setter 报「找不到符号」。
- **关键坑**：Spring Boot 4 默认 Jackson 3 (`tools.jackson.*`)，Jackson 2 需显式引 `com.fasterxml.jackson.core:jackson-databind`（jjwt-jackson 也需要）；Spring Session 序列化器从已标记删除的 `Jackson2JsonRedisSerializer` 改为 Jackson 3 的 `GenericJacksonJsonRedisSerializer.builder().enableUnsafeDefaultTyping().build()`。
- **关键坑**：AWS SDK v2 `S3Client.builder()` 返回顶层 `S3ClientBuilder`，不存在 `S3Client.Builder`；`S3Presigner.Builder` 则存在。
- 32 个 Java 文件 `javax.servlet`→`jakarta.servlet`；删除 FollowQuestionMapper 两个无用导入。
- 验证码：删除 `libs/EasyCaptcha-1.5.0-RELEASE.jar`，自研 `captcha/ImageCaptcha.java` + `captcha/CaptchaUtil.java`（SecureRandom + Java2D，130×48 PNG，session 存小写文本+时间戳，5 分钟过期），保持 `out/ver/clear` 契约，8 处调用只改 import，前端零改动。
- 对象存储：`MinIOConfigProperties`/`MinIOStorageRepositoryImpl` → `S3ConfigProperties`/`S3StorageRepositoryImpl`；`MyConfig` 提供 S3Client + S3Presigner；path-style 兼容 MinIO；配置项改为 `s3.*`。
- `application.yml`：去 Druid type（Hikari 默认）、`spring.redis`→`spring.data.redis`、去掉 Redis 密码（测试 Redis 实测无密码）、`logging.file`→`logging.file.name`+`logging.logback.rollingpolicy`、删 favicon 属性。
- 测试环境实测：`192.168.0.100:3306` root/123456，库 `community`（13 张表齐备）；Redis 6379 无密码；旧 MinIO `192.168.147.132:9000` 不可达（S3 配置为占位，需换成实际端点）。
- 验证：`mvn clean package -DskipTests` BUILD SUCCESS；JDK 25 启动成功（Tomcat 11.0.27、Hikari 连库、定时任务查询正常）；首页/登录注册/问题页/后台/聊天页 HTTP 200；验证码 PNG 与会话校验、S3 预签名 URL、JJWT 签发解析均验证通过；Thymeleaf 3.1 模板在本轮页面冒烟中未发现异常。
