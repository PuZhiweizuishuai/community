## 聊天室输入区回归修复（同日）

用户反馈三点，均为 Vditor 容器与键盘事件细节，已用临时 `/chat-debug` 页面隔离复现后修掉（临时页面与路由已删除）：

- **tooltip 被裁**：`.chat-composer-card` 的 `overflow:hidden` 会裁掉 Vditor 用 `bottom:100%` 向上弹出的按钮提示。改 `overflow:visible` + 工具栏顶部圆角 + `z-index:5`，`.chat-dock` 加 `z-index:1`，提示可盖住消息流。经验：**想让 Vditor 工具栏提示/表情面板正常弹出，外层卡片不能用 `overflow:hidden`**。
- **编辑区盖住发送栏**：Vditor 自带 `.vditor-content{min-height:60px}`，加 ~42px 工具栏 = 102px > 容器 84px，溢出 18px。覆盖 `min-height:0`，桌面高度改 108px（移动端工具栏隐藏时 84px）。
- **回车要按两次**：中文输入法组合态 Enter 的 keydown 是 `isComposing=true` / keyCode 229，原先直接丢掉；改成 keydown 只 `preventDefault+stopPropagation` 拦住 Vditor，发送放到 `keyup`，并用 `compositionend.capture` 兜底（rAF 后再取值，等 Vditor 的 input 回调同步）。另外把 `ready`（等 CDN 上的 Lute 加载完）从 `canSend` 里去掉，否则初始化期间第一次回车也会静默失败。断线时回车给 toast 提示。
- 记住：**聊天类输入框不要在 keydown 里直接发送中文内容**，组合态会吞掉确认候选词的那一下回车。
